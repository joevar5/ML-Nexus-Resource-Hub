# Agents — 30-Day Agentic AI Interview Prep Path

Tool-calling, memory, planning/ReAct, and multi-agent orchestration, broken into a 30-day path: short daily lessons, coding problems, and mini projects for AI engineering interviews.

**30 days · ~45 min/day · 4 phases · 30 lessons · 30 practice problems**

## Curriculum

### Phase 1 — Agent Foundations (Day 1–5)

| Day | Lesson |
|---|---|
| 1 | What is an AI Agent? |
| 2 | The Agent Loop |
| 3 | Goals and Task Breakdown |
| 4 | State and Context |
| 5 | Agent Failure Modes |

### Phase 2 — Tools and Execution (Day 6–12)

| Day | Lesson |
|---|---|
| 6 | Tool Calling Basics |
| 7 | Tool Schemas |
| 8 | Tool Error Handling |
| 9 | Retries and Fallbacks |
| 10 | Structured Output |
| 11 | Multi-Step Tool Use |
| 12 | Mini Project: Research Assistant |

### Phase 3 — RAG, Memory, and Evals (Day 13–20)

| Day | Lesson |
|---|---|
| 13 | RAG Basics |
| 14 | Chunking and Retrieval Quality |
| 15 | Citations and Grounded Answers |
| 16 | Memory in Agents |
| 17 | Short-Term vs Long-Term Context |
| 18 | Agent Evals |
| 19 | Scoring Agent Behavior |
| 20 | Mini Project: Support Agent with RAG |

### Phase 4 — Production and Interview Practice (Day 21–30)

| Day | Lesson |
|---|---|
| 21 | Guardrails |
| 22 | Human-in-the-Loop |
| 23 | Observability |
| 24 | Debugging Agents |
| 25 | Cost and Latency |
| 26 | Agent Architecture |
| 27 | Interview Design Questions |
| 28 | Mixed Hard Problem |
| 29 | Capstone Project |
| 30 | Final Review |

Each lesson pairs a short read with a coding problem and a handful of quiz questions, building from what an agent loop is up through debugging, cost/latency tradeoffs, and mock interview design questions — ending in a capstone project that ties tool use, RAG, memory, and guardrails together.
