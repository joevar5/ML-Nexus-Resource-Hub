# GenAI System Design (GenAI SD)

A structured collection of real-world GenAI System Design questions — systems built around large language models, from grounding responses in external knowledge to generating personalized, context-aware text.

---

## The Story Behind This Repository

Let's be honest: LLM-powered products break in ways classic ML systems don't — hallucination, retrieval quality, prompt drift, latency under generation — and most prep material glosses over these tradeoffs. I built this repository to systematically break down and document real-world GenAI system design questions end-to-end. By collaborating with AI assistants, I've synthesized, structured, and open-sourced templates covering requirements, architecture, training/prompting strategy, and evaluation for the most common LLM product patterns.
